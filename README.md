# ミクの音

MMDモーションを作るときにちょっと便利なMMDスキマツール

![icon](icon.ico)

## これは何？

MikuMikuDance(MMD)には音量調整機能がありません。
このツールは、**自分でスライダーを動かして**MMDの再生音量だけを
個別に調整できる小道具です（Windowsの「音量ミキサー」のMMD専用版）。

※自動で音量が変わったりする機能ではありません。あくまで手動で調整するためのツールです。

さらに、WAVファイルをトリミング・カット・無音挿入・音量調整・他のWAVとの
結合/ミックスをしてそのままMMDに読み込ませる編集パネルも付いています
（**テスト版**機能）。

## ダウンロード

[Releases](../../releases) から `miku_no_oto.exe` をダウンロードしてください。

## 使い方（音量スライダー）

1. `miku_no_oto.exe` を起動する（MMDより先でも後でもOK）
2. 表示されたスライダーを自分で動かすと、MMDの音だけがその場でリアルタイムに大きく/小さくなる
3. 他のアプリの音（VOICEVOXなど）には一切影響しません

## 使い方（WAV編集 → MMDに読み込む）※テスト版機能

音量スライダーの下に、WAVファイルを編集してそのままMMDに読み込ませるパネルがあります。
機能が増えたので「トリム/音量」「カット/無音挿入」「WAV追加/ミックス」の3タブに
分かれています。

- **トリム/音量**: 開始/終了位置の指定、音量(%)の調整
- **カット/無音挿入**: 音声の途中を複数箇所カット（削除してつなげる）／逆に指定位置に
  無音を挿入
- **WAV追加/ミックス**: 別のWAVファイルを末尾に結合、または同時に鳴らして重ねる
  （タイミングもずらせます）。メイン/追加(サブ)WAVのどちらを編集するか選べて、
  波形表示もそれぞれ確認できます
- 波形はウィンドウの横幅に合わせて広がるので、細かい位置確認もしやすくなっています
- 「▶ プレビュー再生」でツール上のまま編集結果を確認でき、「⏪ 早戻し」で
  少し手前に戻って聞き直せます
- 「実行の1つ前に戻す」で直前に実行した時の設定に戻せます（簡易undo）
- 「保存してMMDに読み込む」を押すと、編集したWAVをそのまま起動中のMMDに読み込みます

元のWAVファイルは上書きせず、常に新しいファイルとして保存されます。内部でffmpegを
使用していますが、exe版には同梱済みです。

## 注意事項（重要）

- 音量スライダーは「今聞こえている音」のボリュームを変えるだけです。自動で音量が
  変わったりする機能ではありません。
- WAV編集機能は、選んだファイル自体を上書きすることはありません（常に別名で保存）。
- MMDを一度終了して再起動しても、スライダーはそのまま使えます（自動で再度MMDを見つけ直します）。

## 動作環境

- Windows
- MikuMikuDance（ファイル名に "MikuMikuDance" を含むものであればOK）

## ウイルス対策ソフトの誤検知について

音量を扱う仕組み上、一部のウイルス対策ソフトが誤って警告を出したりブロックすることがあります。
心当たりのある方は、お使いのソフトの除外設定にこのツールを追加してください。
