# ミクの音

MMDモーションを作るときにちょっと便利なMMDスキマツール

![icon](icon.ico)

## これは何？

MikuMikuDance(MMD)には音量調整機能がありません。
このツールは、**自分でスライダーを動かして**MMDの再生音量だけを
個別に調整できる小道具です（Windowsの「音量ミキサー」のMMD専用版）。

※自動で音量が変わったりする機能ではありません。あくまで手動で調整するためのツールです。

## ダウンロード

[Releases](../../releases) から `miku_no_oto.exe` をダウンロードしてください。

## 使い方

1. `miku_no_oto.exe` を起動する（MMDより先でも後でもOK）
2. 表示されたスライダーを自分で動かすと、MMDの音だけがその場でリアルタイムに大きく/小さくなる
3. 他のアプリの音（VOICEVOXなど）には一切影響しません

## 注意事項（重要）

- このツールは「今聞こえている音」のボリュームを変えるだけです。
- WAVファイルや、MMDから書き出した動画/音声ファイルなど、ファイル自体は一切変更・上書きされません。
- MMDを一度終了して再起動しても、スライダーはそのまま使えます（自動で再度MMDを見つけ直します）。

## 動作環境

- Windows
- MikuMikuDance（ファイル名に "MikuMikuDance" を含むものであればOK）

## ウイルス対策ソフトの誤検知について

音量を扱う仕組み上、一部のウイルス対策ソフトが誤って警告を出したりブロックすることがあります。
心当たりのある方は、お使いのソフトの除外設定にこのツールを追加してください。
